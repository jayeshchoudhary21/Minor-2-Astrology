# 🌟 Astro Website (Minor Project)

A modern astrology-based web application built using React. This project provides users with astrology insights, horoscope details, and an interactive and user-friendly interface.

---

## 🚀 Features

* 🔮 Astrology-based predictions
* 📅 Daily horoscope updates
* 🎨 Clean and responsive UI
* ⚡ Fast performance using React
* 📱 Fully mobile-friendly design

---

## 🛠️ Tech Stack

* ⚛️ React.js
* 🎨 CSS / Tailwind CSS
* 🌐 HTML5
* 📦 Node.js & npm

---

## ⚙️ Installation & Setup

1. Clone the repository

```
git clone https://github.com/jayeshchoudhary21/Minor-2-Astrology.git
```

2. Navigate to project folder

```
cd Astro_website
```

3. Install dependencies

```
npm install
```

4. Run the project

```
npm start
```
